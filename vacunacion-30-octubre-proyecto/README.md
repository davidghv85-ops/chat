# Jornada de vacunación · Tzompantepec
Video vertical 1080×1920, 30 fps, 33.85 segundos. Voz original completa y efectos originales de interfaz y transición, sin música. Datos de campaña procedentes del audio entregado el 29 de octubre de 2026.

Banner original de uno.zip, intacto: presentación central de intro y desplazamiento proporcional al pie; permanece visible durante el resto del video. Sin filtros o recoloración en logos. Ilustraciones médicas vectoriales originales, paneles animados y cámara 2.5D; no imágenes clínicas documentales.

Fuentes locales DejaVu Sans / Sans Condensed. HyperFrames 0.8.144, GSAP.

Regenerar: `python3 build.py`, `python3 audio.py`, `npm run check`, `npm run render -- --output renders/jornada-vacunacion-30-octubre.mp4 --quality high --fps 30 --workers 4`.

El texto transcrito usa la grafía municipal correcta Tzompantepec; la voz original no se modifica.
